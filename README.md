# @local/dsh-phone-access

Визитка плагина: [site/index.html](site/index.html) — открывается в браузере без сборки и сервера.

Открывает веб-интерфейс уже запущенного DSH (профиль Desktop) телефону в домашней
сети. Второй листенер поверх TLS, вход по одноразовой ссылке, полный доступ к
сессиям — тот же интерфейс, что на компьютере, включая аппрувы, вопросы, файлы и
терминал.

## Как это устроено

- Хост-половина плагина поднимает `node:https` на адресе из конфига и проксирует
  HTTP и WebSocket в `ctx.webServer.getOrigin()` — то есть в тот же локальный
  листенер, которым пользуется окно Desktop. Окно Desktop не трогается.
- Внутреннюю куку плагин добывает сам: `connection.authenticatedUrl(origin)` →
  `fetch` → 303 → `set-cookie`.
- Телефон авторизуется своей подписанной кукой: одноразовая ссылка
  `https://<host>:<port>/?t=<token>` обменивается на `dsh-phone` (HttpOnly,
  Secure, SameSite=Lax, 30 дней).
- `/ca.crt` отдаёт локальный CA: без него телефон не доверяет сертификату.
- «Отозвать все» ротирует секрет куки и закрывает открытые туннели.

## Конфигурация

```yaml
- id: phone-access
  name: '@local/dsh-phone-access'
  config:
    host: 192.168.1.237   # обязателен: один локальный IPv4 этой машины
    port: 3099
    publicUrl: https://dsh.example.com   # необязателен: внешний адрес для ссылок и QR
    linkTtlMinutes: 10
    cookieDays: 30
    tls:
      mode: auto          # auto | files | off
      # certFile: C:\certs\phone.pem
      # keyFile: C:\certs\phone-key.pem
```

`tls.mode: auto` выпускает собственный CA и листовой сертификат в
`$DSH_HOME/phone-access/tls/` с SAN на `host`, `localhost` и `127.0.0.1`. При смене
адреса сертификат перевыпускается под тем же CA, поэтому установленное на телефоне
доверие продолжает работать.

`publicUrl` — внешний адрес, который видит телефон: ссылки, QR и проверка `Origin`
строятся от него, а слушатель остаётся на `host:port`. Если трафик идёт через
реверс-прокси или туннель, поставьте сюда его корень; тогда SAN сертификата
дополняется именем из `publicUrl`.

## Установка из индекса

Плагин лежит в публичном индексе: https://raw.githubusercontent.com/NuclearAPK/dsh-phone-access/master/index.json. Добавьте адрес в indexes строки plugin-market — плагин появится на вкладке Discover и установится по пину на коммит.

## Включение

1. Добавить пакет в профиль `desktop`: строка `@local/dsh-phone-access` в
   `dsh.profile.bundles` и `link:`-зависимость в `package.json` профиля.
2. `pnpm install` в каталоге профиля.
3. Добавить блок конфигурации выше в `cordis.patch.yml` профиля.
4. Перезапустить DSH. Настройки → «Телефон»: состояние должно быть `listening`.

## Телефон

1. Скачать CA: навести камеру на QR в карточке (он ведёт на `https://<host>:<port>/ca.crt`) или нажать «Скачать CA».
2. Android: Настройки → Безопасность → Шифрование и учётные данные → Установить
   сертификат → Сертификат ЦС. iOS: открыть файл, установить профиль, затем
   «Об этом устройстве» → Доверие сертификатов → включить доверие.
3. Открыть ссылку из карточки («Показать ссылку»). Ссылка одноразовая.
4. Если адрес не открывается — разрешить порт в брандмауэре Windows.

## Ограничения

- Телефон — владелец хоста: полные права, никаких ролей. Только доверенная сеть.
- Режим `tls.mode: off` отдаёт куку открытым текстом; допустим только для отладки.
- Electron-поверхности (нативный выбор папки, «открыть в приложении», drag из ОС,
  микрофон) на телефоне отсутствуют — страница ведёт себя как обычный веб-клиент.
- QR-коды: один ведёт на файл сертификата CA, второй — на одноразовую ссылку входа, выданную кнопкой «Показать ссылку».
- Плагин не публикует хост в интернет и не умеет пробрасывать порты.
